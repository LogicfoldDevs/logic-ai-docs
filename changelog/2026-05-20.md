# v1.41 - Background Agents

## Added

- Background Agents — create autonomous agents that run on a schedule or on-demand
- Agent memory consolidation for storing lessons learned across agent runs
- Per-tool agent permissions controlled from the Policies tab
- Cron scheduling for recurring agent jobs

## Improved

- Streaming v2 with better error recovery
- Memory consolidation triggers automatically when memory exceeds 30KB
