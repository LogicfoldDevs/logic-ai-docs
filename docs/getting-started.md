# Getting Started with LogicAI

LogicAI is an AI-powered assistant that lives inside your Salesforce org. Ask questions in plain English, and it will query your data, create or update records, and help you get work done faster.

## Installation

1. Install the LogicAI managed package from your Logicfold representative
2. After installation, navigate to the **LogicAI Admin** tab in Salesforce
3. Click **Connect to Logicfold** and follow the setup wizard
4. Assign the **Agentfold Admin** permission set to administrators
5. Assign the **Agentfold User** permission set to end users

## Opening LogicAI

Once installed and connected, LogicAI is available as a panel on any record page where an admin has added it via the Lightning App Builder. Users can also access it from the **LogicAI** tab in the app launcher.

## Your First Conversation

Try asking LogicAI something like:

- "Show me my open opportunities closing this month"
- "Create a new contact named John Smith at Acme Corp"
- "What are the top 10 accounts by annual revenue?"

LogicAI understands your org's schema and can work with any standard or custom object you have access to.
