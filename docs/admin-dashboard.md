# Dashboard

The Dashboard is the landing page of the LogicAI admin console. It gives you a high-level view of how LogicAI is being used across your org.

## What You'll See

- **Session count** — Total number of chat sessions started
- **Active users** — Number of unique users who have chatted with LogicAI
- **Credit balance** — Your current remaining AI credits
- **Top users** — Ranked list of your most active LogicAI users
- **Recent logs** — Latest system events and errors at a glance

## Using the Dashboard

The Dashboard is read-only — it's a monitoring view. Use it to:

- Spot adoption trends (are users actually using LogicAI?)
- Catch credit balance issues before they block users
- Quickly jump to recent errors without digging through the Logs tab

If you see a low credit balance, head to the **Credits** tab to purchase more. If you see errors in the recent logs, click through to the **Logs** tab for full details.
