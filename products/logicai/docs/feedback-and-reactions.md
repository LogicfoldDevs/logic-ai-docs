Logic AI lets users rate individual answers and send the team a support request without leaving the chat.

## Message Reactions

Below each Logic AI message are two reaction buttons:

- **👍 Helpful**
- **👎 Not helpful**

Click either one to rate the message. Click the active button again to clear your rating. Reactions are a quick, one-click signal — no comment box appears and no chat content is sent. They help your team understand which answers are landing and which need work.

## Submitting a Support Request

To report a problem or ask for help, click **Get help** in the chat header. This opens the **Submit a request** form:

- **Category** — choose **Bug report**, **Feature request**, **Question**, or **Other**
- **Subject** — a brief summary (up to 200 characters)
- **Description** — describe the issue or request in detail (up to 5,000 characters)

If you opened the form from a specific message, that message is attached as **Regarding message** so the team has context.

Click **Submit ticket** to send it (both Subject and Description are required). You'll see a **Ticket submitted** confirmation when it goes through.

**Tip:** Want to explain *why* an answer wasn't helpful? Give it a 👎, then click **Get help** and file a **Bug report** or **Question** with the detail.
