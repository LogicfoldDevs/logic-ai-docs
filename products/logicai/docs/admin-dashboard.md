The Dashboard is the landing page of the Logic AI admin console. It gives you a high-level view of how Logic AI is being used across your org.

## What You'll See

- **Current balance** — Your remaining AI credits, with the equivalent dollar value
- **Sessions this month** — Number of chat sessions started this month
- **Active users · 30d** — Unique users who have chatted in the last 30 days
- **Avg credits / session** — Average credit spend per session
- **Top users · last 30 days** — Ranked list of your most active Logic AI users by credit usage
- **Recent issues** — The latest errors and warnings at a glance

## Using the Dashboard

The Dashboard is read-only — it's a monitoring view. Use it to:

- Spot adoption trends (are users actually using Logic AI?)
- Catch credit balance issues before they block users
- Quickly see recent errors without digging through the Logs tab

If you see a low credit balance, head to the **Credits** tab to purchase more. If you see errors under **Recent issues**, open the **Logs** tab for full details.
