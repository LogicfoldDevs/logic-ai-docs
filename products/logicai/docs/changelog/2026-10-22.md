## Added

- **[Automatic memory](/products/logicai/docs/your-memory)** — Logic AI now learns and uses what it knows completely on its own. Nobody has to review, approve or rebuild anything:
  - **Uses what it knows** — your preferences become defaults (say you like tables once, and lists come back as tables), it stops asking things it already knows, and vague requests like *"that account"* or *"do the same for the other one"* resolve from what you're working on.
  - **Learns your habits** — after each chat it notices patterns in how you work (formats, default filters, the checks you run on Mondays). A habit is applied once it shows up in two separate chats, and fades if you stop doing it.
  - **Picks up where you left off** — unfinished work is remembered, and a new chat opens with *"Welcome back"* and suggestions like *"Finish the Acme forecast"* or your usual weekly check.
  - **Offers to automate repeat work** — if you keep doing the same task, Logic AI offers once to set it up as a [scheduled agent](/products/logicai/docs/scheduled-agents). Say no and it won't ask again.
  - **Finds the right memory** — facts are found by meaning, not exact words (*"deals"* finds what it knows about opportunities), and the record you have open is taken into account.
  - **Forget in chat** — just say *"forget that…"* and it's gone for good; Logic AI won't quietly learn it back.
- **Company knowledge without approvals** — facts that are true for everyone are used across the org automatically once Logic AI is confident or has heard them in two separate chats. Admins can still edit or delete any of them on the [Memory](/products/logicai/docs/admin-memory) tab.
- **Real PDF and Excel files** — reports are now generated as real PDF files (and data exports as Excel workbooks) saved to the chat, with a proper **Download** button.
- **Email attachments** — Logic AI can attach a report or export it generated (PDF or CSV), or a file already on a record, when it sends an email for you.
- **Rename chats** — rename any chat from the sidebar; your title is kept from then on.
- **Unread & running indicators** — a spinner shows next to a chat while it's working, and a dot marks chats whose reply finished while you were somewhere else.

## Improved

- **Cleaner chat design** — a centered reading column, softer message bubbles, one-line reply actions (thumbs, time and credits on hover), a single rounded message box, and a sidebar grouped by Today / Yesterday / Previous 7 days / Older
- **Clearer progress while Logic AI works** — a running status in plain words (*"Running SOQL query…"*) with a timer, and finished steps shown as an easy-to-scan timeline
- **Chats sort by latest message**, so the conversation you just used is always on top
- **Lower costs on long chats** — memory no longer changes the part of the conversation that is cached, so follow-up messages in a long chat are much cheaper
- **The admin Memory tab is simpler** — it's now just an optional place to see, add, edit or delete company knowledge; the health score, approval queue and "Rebuild from history" button are gone because memory handles all of that itself (it even learns from people's past chats automatically, overnight)

## Changed

- The **Memory** screen in the chat header, the coworker memory panel, and the *"Was it my memory?"* buttons under answers have been removed — memory no longer needs managing. Ask *"what do you know about me?"* to see what Logic AI remembers, and *"forget …"* to remove something.

## Fixed

- Automatic card top-ups (auto-replenish) now reliably add the purchased credits to your balance
- Switching chats now closes the report side panel instead of leaving the previous chat's report open
