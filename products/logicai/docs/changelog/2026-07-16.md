## Added

- **Move a memory** — from the [Your Memory](/products/logicai/docs/your-memory) panel (and the admin [Memory](/products/logicai/docs/admin-memory) review), move any fact between your own memory, a [coworker](/products/logicai/docs/coworkers) you use, and org memory. You only see destinations you can access, and anything sent to org memory is held for admin review
- **Coworker-aware memory** — facts Logic AI learns inside a coworker chat now stay with that coworker instead of your general memory
- **Org memory review gate** — auto-captured org-wide facts now wait for an admin to approve them (👍 / 👎 / edit / move / delete) before they're used in everyone's chats
- **Coworker access policies** — admins can restrict a user to **Coworkers only** (no default chat) or **Disable creating coworkers**, on the org default or per user (see [Policies](/products/logicai/docs/admin-policies#chat--coworkers))

## Fixed

- Chatbot policies now apply correctly for users in orgs with stricter (Private) sharing settings
- Coworkers shared with specific people now open correctly for those teammates
- Multi-step (tool-using) chats no longer hit an intermittent error mid-conversation

## Improved

- Lower credit usage on long, multi-step conversations
- Faster chat and admin console load times
