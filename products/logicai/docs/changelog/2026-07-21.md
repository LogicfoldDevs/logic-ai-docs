## Added

- **[Scheduled Agents](/products/logicai/docs/scheduled-agents)** — ask Logic AI in chat to set up an agent that runs on its own, on a schedule (*"Every Monday at 8am, email me a summary of new leads"*) or on demand. Agents appear in a new **Scheduled Agents** tab where you can watch each run, see what it did, edit it (just by chatting), run it now, or pause it
- **Auto-replenish credits** — save a card on the [Credits](/products/logicai/docs/admin-credits) tab and have Logic AI automatically top up your balance whenever it drops below a threshold you choose, so chats never stop mid-task
- **Transaction history** — the Credits tab now lists every purchase and top-up, grouped by day, with a type filter, a **Download CSV** export, and a **Request receipt** link per transaction
- **[Usage](/products/logicai/docs/admin-usage-limits) tab** — this month's spend and the per-source / per-user spend caps now have their own tab in the admin console, separate from Credits
- **Queue a follow-up** — start typing (or send) your next message while Logic AI is still working on the current one; it sends automatically when the turn finishes, and a live timer shows how long each answer is taking

## Fixed

- **Download CSV** now works inside Salesforce orgs with Lightning Web Security enabled
- CSV export button is easier to click, and stray clicks no longer trigger an accidental download
- Turning off auto-replenish now clears the saved threshold and amount so nothing fires unexpectedly
- Card actions (add / delete) and Stripe checkout now return you to the Credits tab instead of resetting the view

## Improved

- Refreshed the look of the whole admin console and the chat panel to share one consistent theme
- Scheduled Agents run views group their steps and collapse tool calls by default, so a run is easier to skim; run status updates on its own while a job is active
