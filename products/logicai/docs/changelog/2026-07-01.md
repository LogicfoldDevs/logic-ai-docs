## Added

- **[Coworkers](/products/logicai/docs/coworkers)** — create focused chat personas in the sidebar, each with its own memory, colour, and standing instructions; keep them private, share with specific teammates, or open to your whole org
- **[Developer API](/products/logicai/docs/developer/overview)** — a global Apex API (`lai.LogicAI`) to call Logic AI from your own Apex, Flows, and triggers, with a per-call credit multiplier
- **[Monthly spend caps](/products/logicai/docs/developer/registration-spend-caps)** — set USD spend limits per source and per user, with a new per-source and per-user spend breakdown on the [Credits](/products/logicai/docs/admin-credits) tab
- **[Metadata tools](/products/logicai/docs/tools#metadata-tools)** (admins only) — Logic AI can read how your org is built (Apex, Flows, validation/workflow rules, permission sets, LWC/Aura) to explain your automation
- **Smarter [memory](/products/logicai/docs/admin-memory)** — memory is now captured automatically and recalled invisibly, with a health score and 👍/👎 [feedback](/products/logicai/docs/feedback-and-reactions) that auto-tunes how much Logic AI remembers
- **Chats sidebar** — one-line chat rows, delete chats, a resizable divider, and smoother loading

## Fixed

- Fixed a freeze that could occur when giving a message a 👎
- Removed occasional blank assistant messages from the chat

## Improved

- Longer, more reliable timeouts on long-running requests
- Memory can be rebuilt from a full history scan, migrating older memory into the new system
