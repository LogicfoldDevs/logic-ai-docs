## Added

- **[Blueprints](/products/logicai/docs/blueprints)** — save a chat as a named, reusable workflow you can run again anytime, kept private or shared with your team
- **New action tools** Logic AI can use (all off by default, admin-controlled on the [Policies](/products/logicai/docs/admin-policies) tab): send email, send a custom notification, post to Chatter, run a report, create a report, invoke an Apex action, invoke a Flow, and [SOSL search](/products/logicai/docs/tools)
- **Interactive prompts** — Logic AI can show clickable multiple-choice options in the chat instead of making you type your answer
- **Read any file type** — the file reader now handles any attachment, not just PDFs

## Fixed

- **Email now requires approval by default** before anything is sent
- **CSV exports return the full result set** — no longer capped at the query row limit
- Chat loads more smoothly, with steps and approvals shown in the right order
- Tools you've turned on **stay on after a package upgrade** instead of resetting
- Approval chips now clearly show **Approved** or **Denied**
- Fixed an issue that could stop the chat from loading for some users
