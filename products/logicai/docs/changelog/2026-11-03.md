## Added

- **Several chats at once** — start a new chat, or keep working in another one, while Logic AI is still answering somewhere else. Up to four chats can be working at the same time, each with its own spinner in the sidebar.
- **Full chat history** — long chats now show a **Load earlier messages** button at the top, so you can scroll back to the very first message.
- **Picks up after a refresh** — if you refresh the page (or it reloads) while Logic AI is still working, it reopens that chat and carries on with the answer instead of stopping with an error.
- **Offers to schedule repeat reports** — when you ask for a report that looks like something you'd want every day or every week, Logic AI offers to set it up as a [scheduled agent](/products/logicai/docs/scheduled-agents), and makes similar helpful suggestions along the way.
- **The real PDF in the side panel** — once a report has been saved as a PDF, the side panel shows the actual PDF file. A **Preview / PDF** button switches between the two.
- **Resizable side panel** — drag the left edge of the report side panel to make it wider or narrower. It now opens a little wider, and remembers the size you choose.

## Improved

- **Better-looking PDFs** — downloaded PDF reports now look just like the report on screen: the same fonts, headings, tables and colours.
- **Line breaks are kept in PDFs** — lines like an address or invoice details now stay on their own lines instead of running together.
- **Cleaner exports** — CSV and Excel exports put related-record fields in their own columns (for example, an opportunity export now has separate **Account.Name** and **Account.Industry** columns) instead of one column of raw data.
- **Faster sidebar** — a chat is highlighted the moment you click it, without waiting for it to load.

## Fixed

- Switching back and forth between chats while Logic AI is working no longer breaks the answer or mixes messages between chats.
- A new chat no longer shows "thinking" just because another chat is still working.
- Some older replies could show as an empty bubble; they now always show their text.
